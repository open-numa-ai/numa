# Contributing

Thank you for your interest in Numa.

Numa is an early-stage open-source project exploring personal intelligence, long-term memory, knowledge discovery, and reflective AI systems. Contributions are welcome across product thinking, architecture, documentation, research, and implementation.

## Ways to Contribute

- Improve documentation and examples.
- Propose architecture changes or design notes.
- Open issues for unclear behavior, missing context, or broken workflows.
- Contribute prototypes for memory, discovery, research, and reasoning modules.
- Share references, papers, and implementation tradeoffs relevant to personal intelligence systems.

## Contribution Principles

- Keep changes focused and easy to review.
- Prefer clear explanations over clever abstractions.
- Document assumptions, limitations, and open questions.
- Treat privacy, user agency, and data ownership as first-class concerns.

## Development Workflow

1. Fork the repository.
2. Create a focused branch for your change.
3. Make the smallest useful change.
4. Update documentation when behavior or direction changes.
5. Open a pull request with context, tradeoffs, and validation notes.

## Code of Conduct

Be thoughtful, respectful, and constructive. Numa is about helping humans think better; the project culture should reflect that.
