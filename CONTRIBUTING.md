# Contributing to Numa

Thank you for your interest in contributing to Numa!

Numa is an open-source project focused on building scalable, modular, and intelligent AI agent infrastructure. We welcome contributions from developers, researchers, and AI enthusiasts.

There are many ways to contribute:

- Report bugs
- Suggest new features
- Improve documentation
- Submit code changes
- Add examples and integrations
- Improve performance and reliability

---

## Getting Started

Before contributing, please:

1. Read the project documentation.
2. Check existing issues and pull requests.
3. Search before creating a new issue.

Repository:

https://github.com/open-numa-ai/numa

---

# Reporting Issues

If you find a bug or unexpected behavior, please create an issue with:

- A clear description of the problem
- Steps to reproduce
- Expected behavior
- Actual behavior
- Environment information
